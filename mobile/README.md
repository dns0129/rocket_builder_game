# 火箭工坊 · 登月计划（手机版）

电脑版游戏的触屏移植，是一个**独立的 Vite 项目**：有自己的 `package.json`、依赖、贴图和测试，可以单独开发、构建和部署。
玩法、物理和画面与电脑版一致（同一套真实物理、1:10 地月系统、8 项任务），界面针对手机重新设计，支持横屏和竖屏。

## 快速开始

```bash
cd mobile
npm install
npm run dev        # 开发服务器 http://localhost:5174
npm run build      # 生产构建，输出到 mobile/dist/
npm run preview    # 预览生产构建 http://localhost:4174
npm test           # 物理与平衡测试（与电脑版相同）
```

**在手机上调试**：手机和电脑连同一个 Wi-Fi，`npm run dev` 后终端会显示 `Network: http://192.168.x.x:5174`，用手机浏览器打开这个地址即可。

**部署**：`dist/` 是纯静态文件（`base: './'`，放在任意子路径下都能用）。正式发布请使用 **HTTPS**——屏幕常亮、离线缓存、“添加到主屏幕”都要求安全连接。

需要支持 WebGL2 的手机浏览器：iOS / iPadOS 15+ 的 Safari，或安卓上较新的 Chrome / Edge / 三星浏览器。

## 触屏操作

### 总装车间

| 操作 | 说明 |
| --- | --- |
| 底部面板（横屏时在右侧） | **零件**：选分类后点零件，添加到选中零件下方；**结构**：上移 / 下移 / 删除 / 换推进剂 / 调整附件；**性能**：各级 Δv、推重比与设计问题 |
| ▾ / ▴ | 收起 / 展开面板，看完整的火箭 |
| 3D 画面 | 单指拖动旋转，双指捏合缩放、拖动平移；点一下零件即可选中并跳到“结构”页 |
| 顶部火箭名称 ▾ | 改名、保存、载入预设模板或存档 |
| 🚀 发射 | 选择发射台 / 100 km 地球轨道 / 22 km 环月轨道 |

### 飞行（横屏布局，竖屏时自动折成两行）

| 位置 | 控件 | 说明 |
| --- | --- | --- |
| 左下 | 油门滑杆 | 上下拖动；“关 / 满”一键关闭 / 全开；两侧细条是燃料（油）和蒙皮温度（温） |
| 左下 | **分级**（橙色大按钮） | 点火 / 分离下面级 / 抛离助推器 / 启用降落伞。上方卡片显示下一级动作，点卡片查看完整分级序列。0.8 秒内重复点按会被忽略，防止误分离两级 |
| 中下 | 导航球 + **方向舵** | 拖动圆形刻度盘上的橙色旋钮直接设定火箭倾角（0° 竖直，右边向东，180° 竖直向下，可以转满一圈），火箭自动转过去并保持；↺ ↻ 每次 5° |
| 右下 | 姿态摇杆 | 上下 = 俯仰（上推低头），左右 = 偏航；中间有死区、越往外越灵敏；⟲ ⟳ 按住滚转 |
| 右侧 | 工具栏 | **SAS**（保持 / 顺行 / 逆行 / 法向 / 径向 / 机动方向）、**辅助**（自动入轨 / 执行机动 / 自动着陆）、**规划**（机动规划）、**着陆腿**、**降落伞** |
| 顶部 | ◀ 1× ▶ 🗺 🎥 ❚❚ | 时间加速（点中间读数恢复实时）、地图、切换相机、暂停；地图中多出“焦点”按钮 |
| 左上 / 右上 | 遥测 / 轨道面板 | 点一下展开更多数据（离地高度、马赫、过载、气压、质量 / 拱点时间、周期、倾角、任务清单） |
| 画面 | 手势 | 单指拖动旋转视角，双指捏合缩放 |

**执行机动**与电脑版相同：闭环（兰伯特）制导按计划轨道实时修正剩余 Δv，按 Δv 加权中心点火，在物理子步内精确关机，节点还远时自动时间加速、不会越过点火时刻。预测轨迹分片计算、几乎每帧刷新。详见上级目录 README 的“执行机动（闭环制导）”。

平板外接键盘时，电脑版的快捷键（空格、Shift / Ctrl、W/A/S/D、Q/E、← / →、T、G、P、M、N、V、`,` `.` `/`、Esc）依然可用。

## 为手机做的改动

- **界面**：全部重写为触屏界面（`src/ui/builderUI.ts`、`src/ui/hud.ts`、`src/ui/touch.ts`、`src/ui/styles.css`），按钮触控尺寸 ≥ 40 px，适配刘海 / 圆角屏的安全区域，横竖屏两套布局；面板不用 `backdrop-filter`（在 WebGL 画面上实时模糊对手机 GPU 开销很大）。
- **动态分辨率**（`src/render/engine.ts`）：每秒统计帧率，低于约 38 FPS 自动降低渲染分辨率，持续流畅再慢慢提高。设置里三档画质（流畅 / 均衡 / 精细）决定分辨率上下限、阴影和抗锯齿；默认按设备内存与 CPU 核数选择。
- **更小的资源**：地球日间 / 夜间贴图降到 2048×1024（约 0.6 MB，电脑版约 2.1 MB）；阴影贴图比电脑版小一档。
- **总装车间取景**（`src/render/builderScene.ts`）：用相机视口偏移把火箭放在面板之外的可见区域中央，面板展开 / 收起、旋转屏幕时自动重新取景；点选的抖动阈值放宽到 12 px。
- **系统集成**（`src/main.ts`）：
  - 飞行中申请**屏幕常亮**（Wake Lock）；
  - 切到后台**自动暂停**并静音，回来后从暂停菜单继续；
  - 安卓**返回键**在飞行中打开暂停菜单，而不是离开页面；
  - 点火、分离、开伞、着陆、爆炸时**震动反馈**（安卓，可在设置中关闭）；
  - iOS 的音频在第一次触摸后解锁；屏蔽双指缩放页面、长按菜单、下拉刷新；
  - 设置中可进入**全屏**（安卓）。
- **PWA**：`public/manifest.webmanifest` + `public/sw.js`。“添加到主屏幕”后全屏运行，资源会被缓存，**没有网络也能玩**。更换贴图等非哈希资源后请修改 `sw.js` 里的 `CACHE` 版本号。

## 与电脑版的关系

`src/physics/`、`src/rocket/`、`src/game/`、`src/render/`、`src/audio/` 和 `tests/` 从电脑版（仓库根目录 `src/`）复制而来。除下面几处外内容相同，电脑版修改物理或渲染后可以直接复制过来：

| 文件 | 手机版的改动 |
| --- | --- |
| `src/render/engine.ts` | 动态分辨率、各画质的分辨率范围、旋转屏幕后重新取尺寸 |
| `src/render/builderScene.ts` | 面板遮挡时的视口偏移与自动取景、触屏点选阈值、阴影贴图尺寸 |
| `src/render/flightScene.ts` | 新增 `zoomBy()`（双指缩放），阴影贴图尺寸 |
| `src/render/navball.ts` | 新增 `dispose()`：每次飞行结束释放导航球的 WebGL 上下文（手机浏览器的上下文数量上限较低） |
| `src/audio/sound.ts` | 新增 `suspend()`（切到后台时静音） |

火箭存档与电脑版使用相同的 `localStorage` 键名：两个版本部署在同一个域名下时，存档互通；画质、音量等设置各自独立保存。
