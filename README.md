# 火箭工坊 · 登月计划

一款基于真实物理的火箭总装 + 飞行模拟游戏（浏览器运行，Three.js + TypeScript）。
在总装车间用零件拼出你的火箭，从发射台起飞，进入地球轨道，飞向月球、着陆，再安全返回地球。
还可以继续飞向**水星、金星、火星、木星、土星**：太阳与各大行星都在真实的引力下运动，可以飞过去、进入环绕轨道，在火星、金星、水星着陆。

## 快速开始

### Windows：双击启动

1. 下载项目：GitHub 页面上点 **Code → Download ZIP** 并解压（或 `git clone`）。
2. 双击项目文件夹里的 **`Start Game.cmd`**。
   - **第一次运行**：如果电脑上没有 Node.js（或版本太旧），它会询问是否用 Windows 自带的 winget 自动安装 Node.js LTS（也可以选“否”，它会打开 nodejs.org 让你手动安装）；装好后关闭窗口，再双击一次。接着它会自动安装依赖（需要联网，约 1 分钟）。
   - **之后每次**：构建游戏（几秒）→ 启动本地服务器 → 自动在默认浏览器里打开 `http://localhost:4173/`。拉取了新版本时会自动重新安装有变化的依赖。
3. 玩完后关闭那个黑色的命令窗口即可退出。

### macOS：双击启动

1. 下载项目：GitHub 页面上点 **Code → Download ZIP**，在访达里双击 ZIP 解压（或 `git clone`）。
2. 双击项目文件夹里的 **`Start Game.command`**，会打开一个“终端”窗口。
   - **第一次打开被拦截**：从网上下载的脚本没有 Apple 签名，macOS 会提示“无法验证开发者”或“Apple 无法验证……”。点“完成”/“取消”，然后打开 **系统设置 → 隐私与安全性**，在页面底部点 **“仍要打开”**（macOS 14 及更早版本也可以按住 Control 点按文件 → “打开”）。之后再双击就不会拦截了。
   - **第一次运行**：如果没有 Node.js（或版本太旧），装有 Homebrew 时它会询问是否用 `brew install node` 自动安装，否则会打开 nodejs.org，下载 macOS 安装包（.pkg）装好后再双击一次。接着它会自动安装依赖（需要联网，约 1 分钟）。
   - **之后每次**：构建游戏（几秒）→ 启动本地服务器 → 自动在默认浏览器里打开 `http://localhost:4173/`。拉取了新版本时会自动重新安装有变化的依赖。
3. 玩完后在终端窗口按 **Control+C**，或直接关闭窗口（提示“终止进程”时点“终止”）即可退出。

> 如果双击后提示“没有适当的访问权限”（用第三方解压软件解压时可能丢失可执行权限）：打开“终端”，输入 `bash `（后面有一个空格），把 `Start Game.command` 拖进终端窗口，按回车即可。

> 不能直接双击 `dist/index.html`：浏览器禁止以 `file://` 方式加载模块脚本、Web Worker 和贴图，必须通过本地服务器打开。推荐使用 Chrome、Edge 或 Safari。

Linux（或习惯命令行）可以用 `npm install` 之后 `npm start`，效果相同。

### 开发

```bash
npm install
npm start          # 构建并在浏览器中打开游戏（http://localhost:4173）
npm run dev        # 开发模式，浏览器打开 http://localhost:5173
npm run build      # 生产构建，输出到 dist/
npm run preview    # 预览生产构建
npm test           # 物理与平衡测试（含一次完整的自动登月往返模拟）
npm run demos      # 重新生成三份电脑演示 demo（public/demos/*.json）
```

需要支持 WebGL2 的浏览器（Chrome / Edge / Firefox / Safari 最新版）。有独立显卡时可在“设置”里选“高”画质。

### 帧率

时间加速栏右侧显示当前帧率（低于 40 帧时变为橙色）。默认开启**自动分辨率**：帧率低于 48 且瓶颈在显卡时，逐步降低渲染分辨率（最低到 55%）；分辨率降到底仍不够时再依次关闭泛光、阴影并减少大气采样；帧率富余时按相反顺序恢复。可在“设置”里关闭。

其他针对帧率的处理：天空在不透明物体之后绘制，被地球、地面和火箭挡住的像素不再计算大气散射；界面面板不再使用背景模糊；默认帧缓冲不再做无用的多重采样；烟雾粒子上限随画质调整；导航球隔帧刷新；环境反射只在光照明显变化时重新生成。

## 玩法流程

1. **总装车间**：左侧零件库 → 点击添加到选中零件下方；右侧可调整顺序、切换推进剂（液氧煤油 / 液氢液氧）、加装着陆腿/尾翼、捆绑助推器。性能面板实时给出每一级的 Δv、推重比（地球/月球）与燃烧时间，并提示设计问题。
2. **发射**：从海南文昌航天发射场（北纬 19.6°、东经 110.8°）起飞。空格点火，竖直爬升到约 1 km 后用**方向舵**（→ 键，或拖动导航球右侧的圆形刻度盘）让火箭向东倾斜做重力转弯：约 10 km 时 30°，约 45 km 时接近 80°（屏幕上方的“下一步”会实时给出建议倾角，左下角的弹道剖面显示弹道最高点离 100 km 还差多少）。方向舵下方的**航向轴**（[ / ] 键）可以改变倾斜的方位：默认正东，改成正北或正南就进入极地轨道（自动入轨也沿这个航向）。
3. **入轨**：远地点到 ~100 km 后关机，滑行到大气层外，在远地点圆化（近地点 > 70 km）。
4. **奔月**：M 打开地图，机动规划 →“奔月转移”（霍曼转移 + 三体数值精修），执行机动；途中“修正近月点”。从文昌向东发射得到约 19.6° 倾角的停泊轨道，而月球在赤道面内公转，所以奔月要等**发射窗口**：在轨道穿过赤道面的时刻点火，且月球恰好运行到对面。规划器会自动找到最近的窗口（通常 0~4 天，可用 ×10000 时间加速等待）。
5. **环月与着陆**：“月球捕获”→“降低近月点”→ 按“建议点火”倒计时减速，放下着陆腿（G），以 < 3 m/s 触地。
6. **返回**：月面起飞入轨 →“返回地球”→“修正再入角”→ 分离着陆级，逆行姿态（隔热罩朝前）再入，降落伞自动张开。逃逸方向必须大致与月球公转速度相反，环月轨道有倾角时同样要等**返回窗口**（最多约半个月球周期），规划器会自动扫描并用三体积分精修点火时刻与法向分量。

完成 8 项任务（点火升空、触摸太空、环绕地球、奔向月球、环月飞行、月面着陆、月面起飞、凯旋）即通关。
也可在发射前选择“100 km 地球轨道”“22 km 环月轨道”或“80 km 火星轨道”场景直接练习。

7. **飞向行星**（可选）：在地球轨道上按 N 打开机动规划，在“🪐 行星际航行”里选目标（水 / 金 / 火 / 木 / 土），点“🚀 前往……”。规划器会自动寻找发射窗口（可能在几天到几十天后），先给出近似节点；用“⏩ 加速到节点前”等待，临近窗口时会自动用多体引力重新精确计算，然后“执行机动”。进入日心轨道后做一次“中途修正”，抵达后“……捕获”进入环绕轨道。岩质行星可以“降低近拱点”再“自动着陆”；回家时把目标选为“地”，再点“🚀 前往地球”。行星任务（抵达各行星、登陆火星、火星往返）显示在任务面板下方。

右下角的“飞行辅助”（自动入轨 / 执行机动 / 自动着陆）可以帮新手完成各阶段，手动接管油门会自动关闭辅助。

### 执行机动（闭环制导）

规划器给出的机动是“瞬时”的，而真实发动机要在节点前后烧几十秒到几分钟。奔月时 1 m/s 的误差就会让远地点偏差上千公里，所以“执行机动”不是简单地朝一个固定方向烧完 Δv，而是：

- **按 Δv 加权中心点火**：飞船越烧越轻、加速度越来越大，点火时刻取在使 Δv 的“重心”正好落在节点上的位置（比燃烧时间的一半略早），烧完后的位置与瞬时机动一致。
- **兰伯特闭环制导**（`src/game/guidance.ts`）：节点前 20 秒锁定计划中机动后的轨道，取其上约 120° 之后的一点作为目标；点火过程中每帧求解兰伯特问题，算出“以计划的轨道能量经过该点”所需的速度，与当前速度之差就是剩余 Δv。点火偏早偏晚、重力损失、分级停顿和沉底发动机都会被自动补偿。剩余量小于约 1 秒推力时冻结方向。
- **子步精确关机**：在 1/200 秒的物理子步内判断关机，最后一个子步按比例缩小推力；物理加速 ×4 时也不会多烧。
- **不会错过点火**：点“执行机动”时如果节点还远，会自动时间加速到点火前；等待点火期间无论怎么加速，都会在点火前停下来。

效果（测试中）：奔月转移计划近月点 60 km，执行后 57~63 km（以前 1× 时会撞月、×4 物理加速时偏到 850 km）；从近地轨道飞往火星，到达时近火点的偏差从约 1.2 万公里降到约 100 km（中途修正从 21 m/s 降到 1 m/s 以内）；返回地球的再入近地点误差在 1 km 以内。

规划器本身也做了加固：返回地球时如果预测轨迹在近地点之前就撞上地球，用撞击时刻的二体近地点（已包含途中所有摄动）作为连续的代价，而不是飞出月球影响球时的粗略估计；对每个点火时刻求出命中再入走廊所需的 Δv，再选最省的点火时刻（以前约四成情况下会多花 80 m/s）；结果消息报告核对后的预计近地点，而不是目标值。远期节点（例如 20 小时后的返回窗口）的预测轨迹改用数值积分（含月球、太阳摄动）跳到节点前，并缓存起来，地图上显示的机动后轨迹与实际执行结果一致。

### 新手友好

- **“下一步”提示**：屏幕上方始终有一句话告诉你现在该做什么（例如“建议倾角 35°，按 → 再向东倾斜”“滑行至远地点，点‘远拱点圆化’”），整趟登月往返被拆成一个个小目标。
- **自动分级**：当前级燃料耗尽而油门仍打开时自动分级（抛掉空箱、点燃下一级）。
- **自动启用降落伞**：在大气中下落时自动启用，到合适的高度和速度自动张开。
- **更宽容**：零件耐撞速度放宽为 1.5 倍（着陆腿约 18 m/s），再入热流按 0.8 倍计算。
- **∞ 无限燃料模式**：总装车间“发射”按钮下方勾选，或在“设置”里开关（飞行中切换立即生效，设置会保存）。开启后液体燃料箱始终是满的、液体发动机不会熄火，本级 Δv 显示为 ∞，燃料条变成金色；飞行中打开会立刻加满液体燃料，因燃料耗尽而熄火的液体发动机重新工作。固体助推器照常烧完并自动分离——它们无法节流也无法关机，无限燃烧反而没法控制（自动入轨到目标远地点时关不掉发动机）。质量不随燃烧减少，机动规划的燃烧时间按恒定质量估算。任务完成画面会注明本次飞行开启过无限燃料。
- **精简界面**：飞行数据只保留海拔、垂直/水平速度、过载；轨道面板只显示远/近拱点与到达时间；SAS 只保留“保持 / 顺行 / 逆行 / 机动方向”，法向、径向收在“更多”里；分级面板只显示接下来的三级。

## Demo 回放（飞行记录）

**每一次发射都会自动记录**：完整的飞行路径、姿态、油门、分级、着陆腿与降落伞、SAS 与飞行辅助的状态、机动规划，以及当时弹出的每一条提示。

- **何时询问保存**：坠毁时，“任务失败”对话框里直接询问是否保存为 Demo；没坠毁而点“重新发射”“返回总装车间”或打开别的 Demo（即开始新的一次飞行）时，如果这次飞行还没保存，也会先问一次（可以改名，或选“不保存”）。暂停菜单和任务完成对话框里也可以随时“💾 保存 Demo”，再次保存会覆盖同一条记录。
- **存在哪里**：浏览器本地的 IndexedDB 数据库（`rocket-game` 库的 `demoMeta` / `demoData` 两张表），不需要服务器；清除浏览器数据会一并删除。可以“⬇ 导出”成文件发给别人，对方“⬆ 导入”即可回放。
- **回放**：总装车间顶栏或暂停菜单里的“🎬 Demo 回放”。回放直接在游戏里进行，三维视图、地图、HUD、轨迹线都和飞行时一样，火箭按当时的状态分级、点火、开伞；屏幕上方显示当时在做什么（电脑演示的解说 + 飞行辅助状态），右侧“操作记录”列出每一步，点一下就跳过去。

| 回放按键 | 功能 |
| --- | --- |
| 空格 | 暂停 / 继续 |
| ← / → | 上一步 / 下一步（按操作记录跳转） |
| , / . | 回放减速 / 加速（¼× ~ 100×，相对当时的节奏，含当时的时间加速） |
| Home | 从头播放 |
| L | 显示 / 隐藏操作记录 |
| M / V / Tab | 地图 / 相机 / 地图焦点 |
| F2 | 截图模式（回放面板上的 📷 按钮也可以） |
| Esc | 回放菜单（退出回放、换一个 Demo）；截图模式中为退出截图模式 |

时间轴按记录时的真实时间排布（与当时的游玩节奏一致），刻度是操作记录（橙色 = 电脑解说，绿色 = 任务达成，红色 = 坠毁），可以拖动跳转。

库里内置三份由电脑驾驶**默认火箭“登月者 L-1”**完成的全航程飞行，用来看电脑是怎么一步步操作的（默认 4 倍速播放）：

### 记录与回放的做法

- **自适应关键帧**（`src/game/recorder.ts`）：发动机工作、在大气层内或贴近地面时每 0.5~2 秒一帧；真空滑行时大约每 1/3 圈一帧，姿态不随惯性系也不随轨道保持（正在转向）时立即补帧；着陆时存天体固连坐标。位置存的是箭体几何原点（分级时质心会跳变，几何不会）。离散状态与提示另存为事件，燃料每几秒存一次快照。整趟登月往返约 1500 帧、240 KB。
- **插值**（`src/game/replay.ts`）：短间隔用三次埃尔米特插值；长间隔（真空滑行）把两端各自沿开普勒轨道（万有变量法，椭圆 / 双曲线都适用）外推到当前时刻再平滑混合，所以几小时一帧也能精确地画出轨道。测试中入轨加 6 天高倍时间加速滑行，回放位置的最大误差约 6 m。
- **回放不做物理积分**：把插值出来的状态写进一个 `FlightSim`，照常交给飞行场景与 HUD 渲染；分级、开伞、残骸、尾焰、再入等离子体都按记录重现。因为存的是飞行结果而不是操作输入，以后物理或自动驾驶改了，旧的 Demo 仍然能正确回放。

> 修复：“自动着陆”在重力较大的天体（火星）上触地后仍保持最低节流，无法判定为着陆，会一直烧到燃料耗尽并自动分级抛掉着陆级；现在触地即关机。

| 橙色实线 | 弹道剖面里已飞过的动力段（地图不画已飞过的航迹，只画当前的预测轨迹） |

预测轨迹是实时刷新的：轨迹积分被切成小片，主循环每帧最多花约 3 ms（帧率偏低时 1.5 ms）推进它，算完立刻从最新状态开始下一次。发动机工作、转向或高倍时间加速时几乎每一两帧就更新一次（以前每 0.25~0.5 秒一次），不会因为一次算整条轨迹而卡顿；滑行时轨迹基本不变，每 0.1 秒刷新一次。

- **飞行视图**：不画任何轨迹线和远地点 / 落点标签，画面里只有飞船和周围的景物。预测轨迹请看地图（M）和左下角的弹道剖面。
- **弹道剖面**（左下）：横轴为沿轨道的航程，纵轴为高度，同时画出大气层边界（70 km）和目标轨道（100 km）。上升段一边转向一边看弹道的最高点慢慢升到 100 km 线，比看数字直观得多。
- **远/近拱点变化**：地图标记和右上角轨道面板都会显示最近约 1 秒的变化量，绿色 ▲ 表示升高、红色 ▼ 表示降低。

### 截图模式（F2）

右下角的“📷 截图 F2”按钮（回放时在回放面板上的 📷）或 F2 键进入截图模式：**整个屏幕上不显示任何仪表、按钮、提示和轨迹**，默认只留**星空和飞船**——星球、地面、发射台与大气都隐藏，天空变成黑色的星空和银河，阳光也不再被星球挡住，飞船始终被照亮。

- 鼠标照常拖动旋转、滚轮缩放取景，V 换相机；飞船照常飞行（发动机尾焰、烟雾、分离过程都在），可以边飞边拍。
- **B**：在“只有星空和飞船”与“保留星球、地面和发射台”之间切换（选择保存在本地，下次进入时沿用）。
- **Esc** 或再按 **F2** 退出；按 M 打开地图、弹出对话框（例如坠毁）时也会自动退出。在地图里进入截图模式会先回到飞船视图。
- 进入时屏幕底部的操作提示约两秒后自动淡出，之后画面上什么都没有，直接用系统截图即可。

### 地图（M）：默认三维

地图默认是**三维**的：相机围绕焦点转动，**拖动旋转、右键拖动平移、滚轮缩放**，可以从任意角度看轨道面、倾角和转移弹道；背景是随视角转动的三维星空与银河，轨迹线、轨道圈转到星球背后时会被挡住。
工具栏的“3D”按钮可以切换成**二维俯视**（按钮变成“2D”）：相机始终垂直于飞船的轨道平面，只能拖动平移、滚轮缩放（以光标为中心），轨道和弹道没有透视变形。选择会一直沿用到你再切回来。
地球、月球、云层、大气辉光与晨昏线使用飞行视图的同一套三维着色器渲染。
所有轨迹线、轨道圈都是带抗锯齿的细线（线宽两侧各有约 1 像素的透明度渐变），亮度低于泛光阈值，没有多重采样时也不会出现锯齿或“马赛克”。

- **自动**视图（默认）：始终框住整条预测轨迹（三维时相机自动后退到能装下整条轨迹，旋转视角不会退出自动视图）；上升段以当地竖直方向为转轴、从轨道面斜着看，弹道从地平线升起，其余时候以北极方向为转轴。缩放或平移后自动退出。飞船进入另一个天体的影响球时画面不会跳动，而是平滑地移到新的轨迹上。
- **飞船 / 日 水 金 地 月 火 木 土**：跟随飞船，或以某个天体为中心（三维时从太阳一侧斜着看过去，大半个星球是亮的）。Tab 键在“当前天体 → 目标行星 → 太阳 → 飞船”之间循环。可以一直缩小到整个太阳系（到土星轨道之外）。
- 画面中还有：各天体的轨道（按缩放自动淡入淡出，当前目标的轨道更亮）、影响球、放大后可见的大气层边界、比例尺；太远看不清圆盘的行星画成一颗亮星。飞船图标指向机头方向。
- **相遇**：将来才会进入的天体（奔月时的月球、飞往火星时的火星），其轨迹画在“相遇时”该天体所在的位置（虚线圆），转移弹道与环绕段首尾相接，一眼就能看出能否命中。多级相遇（从日心轨道回到地球后再遇到月球）也会逐级换算。

### 方向轴

左上角数据面板旁边的小坐标轴（窄屏时在面板下方）随视角转动，一眼就能看出屏幕上哪边是哪个方向：

- **飞行视图**：当地方向 —— 东（红）、上（绿）、北（蓝），空心圆是反方向（西、下、南）。
- **地图**：模拟所用的赤道坐标系 —— “北”（绿）指向地轴北极，X（红）、Z（蓝）在赤道面内（月球和各行星都在这个面上公转）。从文昌发射的停泊轨道相对这个面倾斜约 19.6°，转动地图就能看出来。
- **点击轴端**：相机转到从该方向看过去（约 0.4 秒的转动动画）。例如地图中点“北”从正上方俯视赤道面，点 X 或 Z 从侧面看轨道倾角；飞行中点“东”从东侧看火箭。二维地图中点击会先切换到三维。

### 方向舵

导航球右侧的圆形刻度盘就是方向舵：0° 为竖直向上，右边是航向（默认正东）、左边是相反方向，正下方为 180°，**可以转满一圈**（360°）。拖动橙色旋钮（或按 ← / →，每秒 35°，越过 180° 时连续转过去）设定倾角，中间的小火箭显示实际姿态；设定角与实际姿态相差很大时（例如直接拖到背面），火箭会沿较近的方向在“竖直—航向”平面内转过去；
火箭的姿态控制（发动机摆动 + 尾翼上的红色舵面 + 指令舱姿控）会自动转到设定角度并保持。点击下方的读数可开关方向舵（开启时从当前姿态接管，包括它实际指向的方位）；飞行辅助工作时，蓝色小三角显示它的目标倾角，拖动方向舵即可接管（油门保持不变）。

**航向轴**：刻度盘下方的“航向 东 090°”就是第二根轴，决定火箭朝哪个方位倾斜（0° 正北、90° 正东、180° 正南、270° 正西）。按 [ / ]（每秒 45°）或两边的 ↶ / ↷（每次 15°）转动，点击读数恢复正东；刻度盘两侧的方位字随之变化。方向舵开启时倾角不变，火箭绕竖直方向转到新的航向。
从北纬 19.6° 的文昌向正东发射得到约 19.6° 倾角的停泊轨道；向正北或正南发射得到经过两极的**极地轨道**，向东北、东南发射得到中间的倾角。“自动入轨”同样沿这个航向转弯，所以发射前在发射台上转好航向、再点“自动入轨”即可。（天体自转目前关闭，任何方位入轨所需的 Δv 都一样。）

### 分离过程

1. 火工品起爆：分离面闪光，一圈燃气向外喷出（大气中是白烟，真空中迅速膨胀消散），伴随碎屑火花；
2. 下面级顶部的 4 台反推火箭工作 1.2 s，使其减速后退并缓慢翻滚，贮箱开口排出推进剂蒸汽；捆绑助推器头尾的分离火箭把它向外推开，机头先向外偏转；
3. 上面级的 4 台沉底发动机工作约 1 s，主发动机在分离 0.8 s 后点火（点火闪光），避免尾焰直接打在下面级上。

这些都是真实的受力：反推、沉底加速度和分离弹簧冲量都进入了动力学计算。

## 物理模型

全部采用真实物理定律，数值积分驱动：

- **引力**：地球、月球、太阳和五颗行星同时作用（地心惯性系下的受限多体问题，含间接项），不是“影响球切换”的近似；轨道预测、机动规划都用同一套积分器（RK4 自适应步长，步长取各天体动力学时间尺度的最小值）。影响球只用于决定“当前天体”、轨道根数与轨迹的分段显示。
- **推进**：齐奥尔科夫斯基方程；比冲随环境气压线性变化（真空发动机在海平面推力大减）；最小节流；固体助推器无法关机或节流；燃料不跨分离器输送。
- **大气**：指数大气（标高 7 km，顶端 70 km），跨音速阻力激增，攻角相关的轴向/法向气动力；压心与质心决定气动稳定性（没有尾翼的火箭在稠密大气中容易翻转），尾翼提供气动操控力矩。
- **刚体姿态**：欧拉方程积分；控制力矩来自指令舱姿态控制系统 + 发动机矢量摆动（推力 × 摆角 × 力臂）+ 尾翼。
- **再入加热**：Sutton-Graves 驻点热流（为降低难度乘以 0.8）+ 蒙皮热容与辐射散热；从月球返回（约 3.1 km/s）必须隔热罩朝前。
- **降落伞**：减速伞（7 km 以下）→ 主伞（2.5 km 以下、< 90 m/s），开伞冲击限制在约 4.5 g。
- **着陆**：弹簧-阻尼接触模型（着陆腿更软），超过零件耐撞速度（已放宽为 1.5 倍）即解体；支持海面溅落。
- **月面地形**：10 个尺度的程序化撞击坑（半径 20 km 到 5 m）+ 丘陵 + 月海。CPU（碰撞）和 GPU（贴图）使用完全相同的整数哈希算法，所以看到的坑就是会撞上的坑。

### 平衡：1:10 地月系统

为了让一枚几十吨的火箭就能完成完整登月（类似《坎巴拉太空计划》的做法），地月系统按 1:10 缩小，**表面重力保持真实值**，时间尺度相应缩为 1/√10，因此所有动力学比例与真实地月系统一致：

| | 地球 | 月球 |
| --- | --- | --- |
| 半径 | 637.1 km | 173.7 km |
| 表面重力 | 9.81 m/s² | 1.625 m/s² |
| 低轨道速度 | ≈ 2.3 km/s（100 km） | ≈ 0.5 km/s（20 km） |
| 自转周期 | 7.57 h | 潮汐锁定 |
| 地月距离 / 月球公转 | 38,440 km / 8.7 天 | 影响球 ≈ 6,600 km |

> **天体自转暂时关闭**：`src/physics/bodies.ts` 中的 `BODY_ROTATION` 设为 `false`，所有天体（含月球的潮汐锁定）都不自转，朝向固定为开局时的样子。代价：发射时得不到地球自转的初速度（入轨多花约 140 m/s）；没有每天的昼夜交替（太阳只随地球公转慢慢移动）；向正东发射的停泊轨道面永远不变——为此把发射场固定在惯性系方位角 70° 处，让这个轨道面正好对准开局两周左右各行星的转移窗口（开局时发射场为午后）。改回 `true` 即恢复上表中的自转和原来的朝向。

参考 Δv（m/s）：入轨 ≈ 3400 · 奔月 ≈ 950 · 捕获 + 着陆 ≈ 1000 · 月面起飞 ≈ 750 · 返回 ≈ 300（再入靠大气减速）。总计约 6300~6500。

预设火箭“登月者 L-1”总质量 35.8 t、总 Δv 7460 m/s，测试中自动驾驶完成整趟任务后仍剩约 300 m/s 余量。

## 太阳系

太阳、水星、金星、火星、木星、土星与地月系统使用**同一个 1:10 比例**（半径、距离缩为 1/10，表面重力保持真实，时间缩为 1/√10）。行星在黄道面内做圆轨道运动，初始相位是为游戏挑选的（让火星、金星的窗口不必等太久），**不是真实星历**。

| --- | --- | --- | --- | --- | --- | --- | --- |
| 太阳 | 69,570 km | 274 m/s² | — | — | — | — | 靠太近会被烤坏（有警告） |

参考：从 100 km 地球轨道飞往火星，转移 Δv ≈ 1100 m/s、飞行约 82 天，中途修正约 20 m/s，火星捕获约 800 m/s（圆化到低轨道；木星、土星只捕获到大椭圆轨道，省很多燃料）。

**行星际规划器**（`src/game/maneuver.ts`）的做法：

1. **猪排图搜索**：在一个会合周期内扫描出发日期 × 飞行时间，用兰伯特问题求日心转移轨道，按“逃逸 Δv + 捕获 Δv + 等待时间”打分；
2. **逃逸几何**：由双曲线超速方向求出停泊轨道上的点火点（考虑停泊轨道倾角带来的平面差），用开普勒外推找到对应的点火时刻；
3. **多体精修**：窗口还远时先给出近似节点，临近窗口（约 1 天前）时自动从当前状态出发，用完整的多体积分对点火时刻和三个 Δv 分量做模式搜索，使目标行星的近拱点落在合适高度（火星约 100 km）；
4. 途中“中途修正”和“捕获”同样基于多体预测。

渲染：太阳为 HDR 发光球体（临边昏暗、米粒组织）加光晕；水星、金星、火星、木星、土星的表面、云带与土星光环都由 GPU 程序化烘焙（火星有奥林帕斯山与极冠，木星有大红斑，金星有带状云）；火星、金星有各自颜色的大气散射（火星的奶油黄天空、金星的昏黄浓云），飞到哪颗星附近就启用哪颗的大气。离太阳越远光照越暗（按距离的平方根衰减，保证外行星仍然看得清）。

## 画面

- **真实地球**：NASA“蓝色大理石”日间地表 + 海底地形、“黑色大理石”夜间城市灯光、水体遮罩（海面高光）和地形起伏图（法线），启动时由 GPU 烘焙成渲染贴图；云层为程序化生成（发射场上空保持晴朗）。贴图加载失败时自动退回程序化地球。
- **地表细节**：在卫星图之上叠加 30 km / 8 km / 2 km 三层程序化细节（颜色斑块 + 起伏凹凸，低太阳角时山脊更立体）、高山积雪，海面有随时间流动的波浪（太阳倒影碎成闪烁的光斑）和近岸浅水色；云层边缘被小尺度噪声侵蚀成一团团积云。细节按每个像素覆盖的地面大小淡入淡出，远看与原图一致、不闪烁。近地面的地形网格上，海面有流动的波浪、岸边有浪花。
- **真实星球贴图**：月球、水星、金星（地表与云顶）、火星、木星、土星和太阳使用 4K（4096×2048）真实贴图（Solar System Scope，基于 NASA 探测器影像，见下文“关于模型与贴图素材”），启动时按画质缩放后烘焙成渲染贴图。岩质天体的法线仍由程序化地形烘焙（与碰撞用的地形是同一套算法），强度减弱一些，免得和贴图自带的明暗叠在一起；火星的奥林帕斯山、塔尔西斯三火山和水手号峡谷的位置与贴图完全对齐。太阳贴图只用来调制米粒组织之上的明暗起伏（近看更明显）。某张贴图加载失败时，该天体自动退回下面的程序化生成。
- 没有真实贴图时，月球、水星、金星、火星表面由 GPU 程序化烘焙（撞击坑、月海、火山）；碰撞用的地形与看到的地形是同一套算法。
- **近看的细节**：贴图只烘焙到半径约 1.3 km 的撞击坑，更小的撞击坑（520 m、210 m、85 m、34 m……）在星球着色器里按每个像素覆盖的地面大小逐级实时计算，并叠加两层细小的明暗与起伏——放大到离月面、水星、火星表面几十公里时仍然清晰，而且这些坑与物理地形完全一致。远看时这些计算自动跳过。
- **气态巨行星**（程序化后备）：多次迭代的流场扭曲让云带边缘卷成涡旋，带边缘有剪切波，细丝沿经度拉长；木星有螺旋结构的大红斑、成串的白色卵形风暴与蓝灰色彩饰，土星北极有六边形；极区布满小气旋。近看时还会实时叠加更细的细丝与小涡旋。
- **太阳**：米粒组织（近看更细）、活动带中成群的太阳黑子（暗本影 + 半影）、靠近临边的光斑，光晕里有几道日冕流光。
- **土星环**：C 环（灰褐、稀薄、有“平台”和麦克斯韦缝）、B 环（最亮、偏暖、由内向外变密）、卡西尼缝（几条暗淡的小环）、A 环（恩克缝、基勒缝），再叠加多个尺度的细密小环（按距离淡入，远处不闪烁）。
- **火星**（物理地形）：奥林帕斯山之外又加了塔尔西斯三火山（阿尔西亚、帕弗尼斯、艾斯克雷尔斯）和水手号峡谷（主峡谷约 300 km 长、18 km 宽、700 m 深，北侧还有一条平行的窄峡谷，按 1:10 缩小）——它们是物理地形的一部分，可以降落在火山坡上或峡谷底部。程序化后备贴图的颜色更丰富（锈红、赭黄、暗色反照率区与风蚀条纹），极冠边缘有螺旋状槽沟。
- **月球、水星的辐射纹**（程序化后备）：最新鲜的一批撞击坑带有向外延伸约 3 倍半径的亮条，在月海的暗底上尤其显眼；辐射纹按与物理地形相同的哈希顺序找到同一批撞击坑。
- **地球云层**：云顶有起伏（越厚越高），迎着太阳的一面亮、背面暗，云团显得立体；厚云更白、薄云略灰。
- 程序化后备的**金星**云层有斜向条纹与极地云环；**水星**更暗、略带棕色。
- 贴图分辨率：低画质 1024，中画质 2048，高画质 4096（真实贴图与火星、月球、气态巨行星的程序化贴图；程序化的水星、金星最高 2048）。
- 单次散射大气（瑞利 + 米氏）：蓝天、日落、空中透视、太空中的大气辉光。
- **昼夜**：保留夜面，但夜面有一层略偏冷的补光（约为白天的 38%，越往夜面深处略暗），地形、云层依然看得清；晨昏线是一段较宽的渐变而不是硬边，附近带一点夕阳的暖色。飞行视图里夜间的地面和火箭也有相应的补光。
- 近地表使用以飞船为中心的同心圆 LOD 地形网格（双精度计算，Web Worker 生成）。
- 泛光 + ACES 色调映射，发动机尾焰（激波菱形、真空膨胀）、烟雾、爆炸、再入等离子体，发射塔与发射场。
- 音效全部由 WebAudio 实时合成。

## 项目结构

```
src/
  physics/   天体、引力、大气、轨道根数、噪声与月面地形、积分器
  rocket/    零件目录、火箭设计与自动分级、Δv 分析
  game/      飞行模拟（刚体、气动、接触、加热、降落伞）、轨迹预测、航迹记录、机动求解、飞行辅助、“下一步”提示、任务、
             飞行记录与回放（recorder / replay / demo / demoStore）、电脑飞行员（demoPilot）
  render/    渲染引擎、星球烘焙与着色器、大气、地形补丁、零件模型、特效、地图轨迹线、导航球、场景
  ui/        总装车间界面、飞行 HUD、方向轴、弹道剖面图、机动规划、Demo 库与回放控制、格式化工具与样式
  audio/     程序化音效
tests/       平衡与物理测试、记录与回放测试
scripts/     生成内置电脑演示 demo 的脚本（npm run demos）
public/demos 内置的三份电脑演示（登月往返、飞向火星、飞向木星）
mobile/      手机版（独立的 Vite 项目，见 mobile/README.md）
```

## 关于模型与贴图素材

除地球与其他星球的贴图外，**所有模型、贴图、音效都是程序化生成的**。

`public/textures/earth/` 中的地球贴图：

| 文件 | 内容 | 来源 |
| --- | --- | --- |
| `day.jpg` | 4096×2048 日间地表 + 海底地形 | NASA Blue Marble（公有领域） |
| `night.jpg` | 4096×2048 夜间灯光 | NASA Black Marble（公有领域） |
| `water.png` | 水体遮罩（白 = 水） | 开源项目 three-globe 示例素材 |
| `topo.png` | 地形起伏（灰度高程） | 开源项目 three-globe 示例素材 |

这些文件取自 [three-globe](https://github.com/vasturiano/three-globe)（MIT 许可）的 `example/img` 目录，原始影像来自 NASA Visible Earth。

`public/textures/planets/` 中的星球贴图（均为 4096×2048 等距柱状投影，北在上、经度 0 在图中央）：

| 文件 | 内容 | 主要数据来源 |
| --- | --- | --- |
| `moon.jpg` | 月面 | NASA LRO（月球勘测轨道器） |
| `mercury.jpg` | 水星地表 | NASA MESSENGER |
| `venus_surface.jpg` | 金星地表（雷达测绘） | NASA 麦哲伦号 |
| `venus_clouds.jpg` | 金星云顶 | NASA 影像 |
| `mars.jpg` | 火星地表 | NASA 海盗号 / MGS |
| `jupiter.jpg` | 木星 | NASA 卡西尼号 |
| `saturn.jpg` | 土星 | NASA 卡西尼号 |
| `sun.jpg` | 太阳 | NASA SDO 影像 |

贴图作者：[Solar System Scope](https://www.solarsystemscope.com/textures/)，按 [知识共享 署名 4.0 国际许可协议（CC BY 4.0）](https://creativecommons.org/licenses/by/4.0/) 使用。原始贴图中月球、水星、金星地表、火星为 8192×4096，这里用 Lanczos 缩小到 4096×2048；木星、土星、太阳与金星云顶原本就是 4096×2048；全部重新压缩为 JPEG（质量 90）。手机版只带一张 2048×1024 的月球贴图（`mobile/public/textures/planets/moon.jpg`）。

如果想进一步提升画质，可以提供下面这些素材（我可以帮你接入）：

1. **更高分辨率的地球贴图**（8K/16K Blue Marble、真实云图），近地时地表会更清晰。
2. **月球位移图**（NASA CGI Moon Kit 的 LOLA 高程，公有领域）：让法线与月面真实地形一致（目前法线来自程序化地形）。
3. **火箭零件 3D 模型**（glTF/GLB）：指令舱、燃料箱、各型发动机、分离器、着陆腿、尾翼、整流罩等。约定：单位米，原点在零件底面中心，+Y 向上，尺寸与 `parts.ts` 中的直径/高度一致，PBR 材质。
4. **发射塔 / 发射场 / 总装厂房** 的 GLB 模型。
5. **HDRI 环境贴图**（例如 Poly Haven 的 CC0 厂房/天空 HDRI），用于总装车间的反射。
6. （可选）发动机、分离、风噪等**音效采样**。
