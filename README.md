# 火箭工坊 · 登月计划

一款基于真实物理的火箭总装 + 飞行模拟游戏（浏览器运行，Three.js + TypeScript）。
在总装车间用零件拼出你的火箭，从发射台起飞，进入地球轨道，飞向月球、着陆，再安全返回地球。

## 快速开始

```bash
npm install
npm run dev        # 开发模式，浏览器打开 http://localhost:5173
npm run build      # 生产构建，输出到 dist/
npm run preview    # 预览生产构建
npm test           # 物理与平衡测试（含一次完整的自动登月往返模拟）
```

需要支持 WebGL2 的浏览器（Chrome / Edge / Firefox / Safari 最新版）。有独立显卡时可在“设置”里选“高”画质。

### 手机版

`mobile/` 目录是独立的手机版项目（触屏操作、横竖屏布局、动态分辨率、可添加到主屏幕离线游玩），玩法与物理和电脑版相同：

```bash
cd mobile
npm install
npm run dev        # 手机与电脑连同一 Wi-Fi，用手机打开终端里显示的 Network 地址
npm run build      # 输出到 mobile/dist/
```

详见 [mobile/README.md](mobile/README.md)。

## 玩法流程

1. **总装车间**：左侧零件库 → 点击添加到选中零件下方；右侧可调整顺序、切换推进剂（液氧煤油 / 液氢液氧）、加装着陆腿/尾翼、捆绑助推器。性能面板实时给出每一级的 Δv、推重比（地球/月球）与燃烧时间，并提示设计问题。
2. **发射**：从海南文昌航天发射场（北纬 19.6°、东经 110.8°）起飞。空格点火，竖直爬升到约 1 km 后用**方向舵**（→ 键，或拖动导航球下方的刻度盘）让火箭向东倾斜做重力转弯：约 10 km 时 30°，约 45 km 时接近 80°。
3. **入轨**：远地点到 ~100 km 后关机，滑行到大气层外，在远地点圆化（近地点 > 70 km）。
4. **奔月**：M 打开地图，机动规划 →“奔月转移”（霍曼转移 + 三体数值精修），执行机动；途中“修正近月点”。从文昌向东发射得到约 19.6° 倾角的停泊轨道，而月球在赤道面内公转，所以奔月要等**发射窗口**：在轨道穿过赤道面的时刻点火，且月球恰好运行到对面。规划器会自动找到最近的窗口（通常 0~4 天，可用 ×10000 时间加速等待）。
5. **环月与着陆**：“月球捕获”→“降低近月点”→ 按“建议点火”倒计时减速，放下着陆腿（G），以 < 3 m/s 触地。
6. **返回**：月面起飞入轨 →“返回地球”→“修正再入角”→ 分离着陆级，逆行姿态（隔热罩朝前）再入，降落伞自动张开。逃逸方向必须大致与月球公转速度相反，环月轨道有倾角时同样要等**返回窗口**（最多约半个月球周期），规划器会自动扫描并用三体积分精修点火时刻与法向分量。

完成 8 项任务（点火升空、触摸太空、环绕地球、奔向月球、环月飞行、月面着陆、月面起飞、凯旋）即通关。
也可在发射前选择“100 km 地球轨道”或“22 km 环月轨道”场景直接练习。

右下角的“飞行辅助”（自动入轨 / 执行机动 / 自动着陆）可以帮新手完成各阶段，手动接管油门会自动关闭辅助。

### 方向舵

导航球下方的半圆刻度盘就是方向舵：0° 为竖直向上，右边向东、左边向西。拖动橙色旋钮（或按 ← / →，每秒 35°）设定倾角，中间的小火箭显示实际姿态；
火箭的姿态控制（发动机摆动 + 尾翼上的红色舵面 + 指令舱姿控）会自动转到设定角度并保持。点击下方的读数可开关方向舵；飞行辅助工作时，蓝色小三角显示它的目标倾角，拖动方向舵即可接管（油门保持不变）。

### 分离过程

1. 火工品起爆：分离面闪光，一圈燃气向外喷出（大气中是白烟，真空中迅速膨胀消散），伴随碎屑火花；
2. 下面级顶部的 4 台反推火箭工作 1.2 s，使其减速后退并缓慢翻滚，贮箱开口排出推进剂蒸汽；捆绑助推器头尾的分离火箭把它向外推开，机头先向外偏转；
3. 上面级的 4 台沉底发动机工作约 1 s，主发动机在分离 0.8 s 后点火（点火闪光），避免尾焰直接打在下面级上。

这些都是真实的受力：反推、沉底加速度和分离弹簧冲量都进入了动力学计算。

## 物理模型

全部采用真实物理定律，数值积分驱动：

- **引力**：地球 + 月球的受限三体问题（地心惯性系，含间接项），不是“影响球切换”的近似；轨道预测、机动规划都用同一套积分器（RK4 自适应步长）。
- **推进**：齐奥尔科夫斯基方程；比冲随环境气压线性变化（真空发动机在海平面推力大减）；最小节流；固体助推器无法关机或节流；燃料不跨分离器输送。
- **大气**：指数大气（标高 7 km，顶端 70 km），跨音速阻力激增，攻角相关的轴向/法向气动力；压心与质心决定气动稳定性（没有尾翼的火箭在稠密大气中容易翻转），尾翼提供气动操控力矩。
- **刚体姿态**：欧拉方程积分；控制力矩来自指令舱姿态控制系统 + 发动机矢量摆动（推力 × 摆角 × 力臂）+ 尾翼。
- **再入加热**：Sutton-Graves 驻点热流 + 蒙皮热容与辐射散热；从月球返回（约 3.1 km/s）必须隔热罩朝前。
- **降落伞**：减速伞（7 km 以下）→ 主伞（2.5 km 以下、< 90 m/s），开伞冲击限制在约 4.5 g。
- **着陆**：弹簧-阻尼接触模型（着陆腿更软），超过零件耐撞速度即解体；支持海面溅落。
- **月面地形**：10 个尺度的程序化撞击坑（半径 20 km 到 5 m）+ 丘陵 + 月海。CPU（碰撞）和 GPU（贴图）使用完全相同的整数哈希算法，所以看到的坑就是会撞上的坑。

### 平衡：1:10 地月系统

为了让一枚几十吨的火箭就能完成完整登月（类似《坎巴拉太空计划》的做法），地月系统按 1:10 缩小，**表面重力保持真实值**，时间尺度相应缩为 1/√10，因此所有动力学比例与真实地月系统一致：

| | 地球 | 月球 |
| --- | --- | --- |
| 半径 | 637.1 km | 173.7 km |
| 表面重力 | 9.81 m/s² | 1.625 m/s² |
| 低轨道速度 | ≈ 2.3 km/s（100 km） | ≈ 0.5 km/s（20 km） |
| 自转周期 | 7.57 h | 潮汐锁定 |
| 地月距离 / 月球公转 | 38,440 km / 8.7 天 | 影响球 ≈ 6,600 km |

参考 Δv（m/s）：入轨 ≈ 3400 · 奔月 ≈ 950 · 捕获 + 着陆 ≈ 1000 · 月面起飞 ≈ 750 · 返回 ≈ 300（再入靠大气减速）。总计约 6300~6500。

预设火箭“登月者 L-1”总质量 35.8 t、总 Δv 7460 m/s，测试中自动驾驶完成整趟任务后仍剩约 300 m/s 余量。

## 画面

- **真实地球**：NASA“蓝色大理石”日间地表 + 海底地形、“黑色大理石”夜间城市灯光、水体遮罩（海面高光）和地形起伏图（法线），启动时由 GPU 烘焙成渲染贴图；云层为程序化生成（发射场上空保持晴朗）。贴图加载失败时自动退回程序化地球。
- 月球表面由 GPU 程序化烘焙（月海、10 个尺度的撞击坑）。
- 单次散射大气（瑞利 + 米氏）：蓝天、日落、空中透视、太空中的大气辉光。
- 近地表使用以飞船为中心的同心圆 LOD 地形网格（双精度计算，Web Worker 生成）。
- 泛光 + ACES 色调映射，发动机尾焰（激波菱形、真空膨胀）、烟雾、爆炸、再入等离子体，发射塔与发射场。
- 音效全部由 WebAudio 实时合成。

## 关于模型与贴图素材

除地球贴图外，**所有模型、贴图、音效都是程序化生成的**。

`public/textures/earth/` 中的地球贴图：

| 文件 | 内容 | 来源 |
| --- | --- | --- |
| `day.jpg` | 4096×2048 日间地表 + 海底地形 | NASA Blue Marble（公有领域） |
| `night.jpg` | 4096×2048 夜间灯光 | NASA Black Marble（公有领域） |
| `water.png` | 水体遮罩（白 = 水） | 开源项目 three-globe 示例素材 |
| `topo.png` | 地形起伏（灰度高程） | 开源项目 three-globe 示例素材 |

这些文件取自 [three-globe](https://github.com/vasturiano/three-globe)（MIT 许可）的 `example/img` 目录，原始影像来自 NASA Visible Earth。

如果想进一步提升画质，可以提供下面这些素材（我可以帮你接入）：

1. **更高分辨率的地球贴图**（8K/16K Blue Marble、真实云图），近地时地表会更清晰。
2. **月球贴图**（NASA CGI Moon Kit：LRO 彩色图 + 位移图，公有领域），用于远景；近景仍由程序化撞击坑提供细节。
3. **火箭零件 3D 模型**（glTF/GLB）：指令舱、燃料箱、各型发动机、分离器、着陆腿、尾翼、整流罩等。约定：单位米，原点在零件底面中心，+Y 向上，尺寸与 `parts.ts` 中的直径/高度一致，PBR 材质。
4. **发射塔 / 发射场 / 总装厂房** 的 GLB 模型。
5. **HDRI 环境贴图**（例如 Poly Haven 的 CC0 厂房/天空 HDRI），用于总装车间的反射。
6. （可选）发动机、分离、风噪等**音效采样**。
