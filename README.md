# 火箭工坊 · 登月计划

一款基于真实物理的火箭总装 + 飞行模拟游戏（浏览器运行，Three.js + TypeScript）。
在总装车间用零件拼出你的火箭，从发射台起飞，进入地球轨道，飞向月球、着陆，再安全返回地球。
还可以继续飞向**水星、金星、火星、木星、土星**：太阳与各大行星都在真实的引力下运动，可以飞过去、进入环绕轨道，在火星、金星、水星着陆。

## 快速开始

### Windows：双击启动

1. 下载项目：GitHub 页面上点 **Code → Download ZIP** 并解压（或 `git clone`）。
2. 双击项目文件夹里的 **`Start Game.cmd`**。
   - **第一次运行**：如果电脑上没有 Node.js（或版本太旧），它会询问是否用 Windows 自带的 winget 自动安装 Node.js LTS（也可以选“否”，它会打开 nodejs.org 让你手动安装）；装好后关闭窗口，再双击一次。接着它会自动安装依赖（需要联网，约 1 分钟）。
   - **之后每次**：构建游戏（几秒）→ 启动本地服务器 → 自动在默认浏览器里打开 `http://localhost:4173/`。拉取了新版本时会自动重新安装有变化的依赖。
3. 玩完后关闭那个黑色的命令窗口即可退出。

> 不能直接双击 `dist/index.html`：浏览器禁止以 `file://` 方式加载模块脚本、Web Worker 和贴图，必须通过本地服务器打开。推荐使用 Chrome 或 Edge。

其他系统（或习惯命令行）可以用 `npm install` 之后 `npm start`，效果相同。

### 开发

```bash
npm install
npm start          # 构建并在浏览器中打开游戏（http://localhost:4173）
npm run dev        # 开发模式，浏览器打开 http://localhost:5173
npm run build      # 生产构建，输出到 dist/
npm run preview    # 预览生产构建
npm test           # 物理与平衡测试（含一次完整的自动登月往返模拟）
npm run demos      # 重新生成三份电脑演示 demo（public/demos/*.json）
```

需要支持 WebGL2 的浏览器（Chrome / Edge / Firefox / Safari 最新版）。有独立显卡时可在“设置”里选“高”画质。

### 帧率

时间加速栏右侧显示当前帧率（低于 40 帧时变为橙色）。默认开启**自动分辨率**：帧率低于 48 且瓶颈在显卡时，逐步降低渲染分辨率（最低到 55%）；分辨率降到底仍不够时再依次关闭泛光、阴影并减少大气采样；帧率富余时按相反顺序恢复。可在“设置”里关闭。

其他针对帧率的处理：天空在不透明物体之后绘制，被地球、地面和火箭挡住的像素不再计算大气散射；界面面板不再使用背景模糊；默认帧缓冲不再做无用的多重采样；烟雾粒子上限随画质调整；导航球隔帧刷新；环境反射只在光照明显变化时重新生成。

### 手机版

`mobile/` 目录是独立的手机版项目（触屏操作、横竖屏布局、动态分辨率、可添加到主屏幕离线游玩），玩法与物理和电脑版相同。

> 注意：手机版是从较早的电脑版移植的（登月往返玩法），**暂不包含**之后加入的太阳系行星、二维地图与三维游览、昼夜补光、Demo 回放等改动。

```bash
cd mobile

npm run dev        # 手机与电脑连同一 Wi-Fi，用手机打开终端里显示的 Network 地址
npm run build      # 输出到 mobile/dist/
```

详见 [mobile/README.md](mobile/README.md)。

## 玩法流程

1. **总装车间**：左侧零件库 → 点击添加到选中零件下方；右侧可调整顺序、切换推进剂（液氧煤油 / 液氢液氧）、加装着陆腿/尾翼、捆绑助推器。性能面板实时给出每一级的 Δv、推重比（地球/月球）与燃烧时间，并提示设计问题。
2. **发射**：从海南文昌航天发射场（北纬 19.6°、东经 110.8°）起飞。空格点火，竖直爬升到约 1 km 后用**方向舵**（→ 键，或拖动导航球右侧的刻度盘）让火箭向东倾斜做重力转弯：约 10 km 时 30°，约 45 km 时接近 80°（屏幕上方的“下一步”会实时给出建议倾角，左下角的弹道剖面显示弹道最高点离 100 km 还差多少）。
3. **入轨**：远地点到 ~100 km 后关机，滑行到大气层外，在远地点圆化（近地点 > 70 km）。
4. **奔月**：M 打开地图，机动规划 →“奔月转移”（霍曼转移 + 三体数值精修），执行机动；途中“修正近月点”。从文昌向东发射得到约 19.6° 倾角的停泊轨道，而月球在赤道面内公转，所以奔月要等**发射窗口**：在轨道穿过赤道面的时刻点火，且月球恰好运行到对面。规划器会自动找到最近的窗口（通常 0~4 天，可用 ×10000 时间加速等待）。
5. **环月与着陆**：“月球捕获”→“降低近月点”→ 按“建议点火”倒计时减速，放下着陆腿（G），以 < 3 m/s 触地。
6. **返回**：月面起飞入轨 →“返回地球”→“修正再入角”→ 分离着陆级，逆行姿态（隔热罩朝前）再入，降落伞自动张开。逃逸方向必须大致与月球公转速度相反，环月轨道有倾角时同样要等**返回窗口**（最多约半个月球周期），规划器会自动扫描并用三体积分精修点火时刻与法向分量。

完成 8 项任务（点火升空、触摸太空、环绕地球、奔向月球、环月飞行、月面着陆、月面起飞、凯旋）即通关。
也可在发射前选择“100 km 地球轨道”“22 km 环月轨道”或“80 km 火星轨道”场景直接练习。

7. **飞向行星**（可选）：在地球轨道上按 N 打开机动规划，在“🪐 行星际航行”里选目标（水 / 金 / 火 / 木 / 土），点“🚀 前往……”。规划器会自动寻找发射窗口（可能在几天到几十天后），先给出近似节点；用“⏩ 加速到节点前”等待，临近窗口时会自动用多体引力重新精确计算，然后“执行机动”。进入日心轨道后做一次“中途修正”，抵达后“……捕获”进入环绕轨道。岩质行星可以“降低近拱点”再“自动着陆”；回家时把目标选为“地”，再点“🚀 前往地球”。行星任务（抵达各行星、登陆火星、火星往返）显示在任务面板下方。

右下角的“飞行辅助”（自动入轨 / 执行机动 / 自动着陆）可以帮新手完成各阶段，手动接管油门会自动关闭辅助。

## Demo 回放（飞行记录）

**每一次发射都会自动记录**：完整的飞行路径、姿态、油门、分级、着陆腿与降落伞、SAS 与飞行辅助的状态、机动规划，以及当时弹出的每一条提示。

- **何时询问保存**：坠毁时，“任务失败”对话框里直接询问是否保存为 Demo；没坠毁而点“重新发射”“返回总装车间”或打开别的 Demo（即开始新的一次飞行）时，如果这次飞行还没保存，也会先问一次（可以改名，或选“不保存”）。暂停菜单和任务完成对话框里也可以随时“💾 保存 Demo”，再次保存会覆盖同一条记录。
- **存在哪里**：浏览器本地的 IndexedDB 数据库（`rocket-game` 库的 `demoMeta` / `demoData` 两张表），不需要服务器；清除浏览器数据会一并删除。可以“⬇ 导出”成文件发给别人，对方“⬆ 导入”即可回放。
- **回放**：总装车间顶栏或暂停菜单里的“🎬 Demo 回放”。回放直接在游戏里进行，三维视图、二维地图、HUD、轨迹线都和飞行时一样，火箭按当时的状态分级、点火、开伞；屏幕上方显示当时在做什么（电脑演示的解说 + 飞行辅助状态），右侧“操作记录”列出每一步，点一下就跳过去。

| 回放按键 | 功能 |
| --- | --- |
| 空格 | 暂停 / 继续 |
| ← / → | 上一步 / 下一步（按操作记录跳转） |
| , / . | 回放减速 / 加速（¼× ~ 100×，相对当时的节奏，含当时的时间加速） |
| Home | 从头播放 |
| L | 显示 / 隐藏操作记录 |
| M / V / Tab | 地图 / 相机 / 地图焦点 |
| Esc | 回放菜单（退出回放、换一个 Demo） |

时间轴按记录时的真实时间排布（与当时的游玩节奏一致），刻度是操作记录（橙色 = 电脑解说，绿色 = 任务达成，红色 = 坠毁），可以拖动跳转。

### 记录与回放的做法

- **自适应关键帧**（`src/game/recorder.ts`）：发动机工作、在大气层内或贴近地面时每 0.5~2 秒一帧；真空滑行时大约每 1/3 圈一帧，姿态不随惯性系也不随轨道保持（正在转向）时立即补帧；着陆时存天体固连坐标。位置存的是箭体几何原点（分级时质心会跳变，几何不会）。离散状态与提示另存为事件，燃料每几秒存一次快照。整趟登月往返约 1500 帧、240 KB。
- **插值**（`src/game/replay.ts`）：短间隔用三次埃尔米特插值；长间隔（真空滑行）把两端各自沿开普勒轨道（万有变量法，椭圆 / 双曲线都适用）外推到当前时刻再平滑混合，所以几小时一帧也能精确地画出轨道。测试中入轨加 6 天高倍时间加速滑行，回放位置的最大误差约 6 m。
- **回放不做物理积分**：把插值出来的状态写进一个 `FlightSim`，照常交给飞行场景与 HUD 渲染；分级、开伞、残骸、尾焰、再入等离子体都按记录重现。因为存的是飞行结果而不是操作输入，以后物理或自动驾驶改了，旧的 Demo 仍然能正确回放。

> 修复：“自动着陆”在重力较大的天体（火星）上触地后仍保持最低节流，无法判定为着陆，会一直烧到燃料耗尽并自动分级抛掉着陆级；现在触地即关机。

### 新手友好

- **“下一步”提示**：屏幕上方始终有一句话告诉你现在该做什么（例如“建议倾角 35°，按 → 再向东倾斜”“滑行至远地点，点‘远拱点圆化’”），整趟登月往返被拆成一个个小目标。
- **自动分级**：当前级燃料耗尽而油门仍打开时自动分级（抛掉空箱、点燃下一级）。
- **自动启用降落伞**：在大气中下落时自动启用，到合适的高度和速度自动张开。
- **更宽容**：零件耐撞速度放宽为 1.5 倍（着陆腿约 18 m/s），再入热流按 0.8 倍计算。
- **精简界面**：飞行数据只保留海拔、垂直/水平速度、过载；轨道面板只显示远/近拱点与到达时间；SAS 只保留“保持 / 顺行 / 逆行 / 机动方向”，法向、径向收在“更多”里；分级面板只显示接下来的三级。

## 轨迹显示

轨迹是这个游戏的核心，所以在每个视图里都画得很醒目，而且**任何操作引起的变化都能一眼看出来**：

| 线条 | 含义 |
| --- | --- |
| 橙色实线 | 已飞过的航迹中发动机工作的部分（动力段） |
| 淡蓝实线 | 已飞过的航迹中滑行的部分 |
| 青色亮线（带流动光点） | 从火箭当前位置出发的预测轨迹；月球附近为紫色，机动节点之后为橙色 |
| 预测线末段变红 | 这条弹道将会撞上地面 |
| 白色淡线 | 约 1 秒前的预测轨迹（“幽灵轨迹”）。转向、点火时它和当前轨迹分开，两者之间的差距就是你的操作带来的变化；轨迹不变时两条线重合 |

- **飞行视图**：航迹从发射台一路连到火箭，预测弹道从箭头向前延伸，并标出“远地点 / 预计落点”及到达时间。都换算到随地球自转的坐标系，所以与地面、发射台对得上。
- **弹道剖面**（左下）：横轴为沿轨道的航程，纵轴为高度，同时画出大气层边界（70 km）和目标轨道（100 km）。上升段一边转向一边看弹道的最高点慢慢升到 100 km 线，比看数字直观得多。
- **远/近拱点变化**：地图标记和右上角轨道面板都会显示最近约 1 秒的变化量，绿色 ▲ 表示升高、红色 ▼ 表示降低。

### 二维地图（M）

地图改为**二维俯视**：相机始终垂直于飞船的轨道平面，只能**拖动平移、滚轮缩放**（以光标为中心），不再三维旋转，轨道和弹道没有透视变形。
地球、月球、云层、大气辉光与晨昏线仍使用飞行视图的同一套三维着色器渲染，保留原来的质感。
所有轨迹线、轨道圈都是带抗锯齿的细线（线宽两侧各有约 1 像素的透明度渐变），亮度低于泛光阈值，没有多重采样时也不会出现锯齿或“马赛克”。

- **自动**视图（默认）：自动缩放并平移，始终框住整条预测轨迹；上升段让当地竖直方向朝上，弹道像二维火箭游戏一样从地平线升起。手动拖动或缩放后自动退出。
- **飞船 / 日 水 金 地 月 火 木 土**：跟随飞船（当地“上”朝上），或以某个天体为中心。Tab 键在“当前天体 → 目标行星 → 太阳 → 飞船”之间循环。可以一直缩小到整个太阳系（到土星轨道之外）。
- **三维游览**：点选某个天体（日 水 金 地 月 火 木 土）时进入三维视图，**拖动旋转、滚轮缩放**，可以绕着星球从任意角度观看，背景是随视角转动的三维星空与银河；轨迹线、轨道圈转到星球背后时会被挡住。工具栏的“3D”按钮可以在二维地图和三维游览之间切换。
- 画面中还有：各天体的轨道（按缩放自动淡入淡出，当前目标的轨道更亮）、影响球、放大后可见的大气层边界、比例尺；太远看不清圆盘的行星画成一颗亮星。飞船图标指向机头方向。
- **相遇**：将来才会进入的天体（奔月时的月球、飞往火星时的火星），其轨迹画在“相遇时”该天体所在的位置（虚线圆），转移弹道与环绕段首尾相接，一眼就能看出能否命中。多级相遇（从日心轨道回到地球后再遇到月球）也会逐级换算。

### 方向舵

导航球右侧的半圆刻度盘就是方向舵：0° 为竖直向上，右边向东、左边向西。拖动橙色旋钮（或按 ← / →，每秒 35°）设定倾角，中间的小火箭显示实际姿态；
火箭的姿态控制（发动机摆动 + 尾翼上的红色舵面 + 指令舱姿控）会自动转到设定角度并保持。点击下方的读数可开关方向舵；飞行辅助工作时，蓝色小三角显示它的目标倾角，拖动方向舵即可接管（油门保持不变）。

### 分离过程

1. 火工品起爆：分离面闪光，一圈燃气向外喷出（大气中是白烟，真空中迅速膨胀消散），伴随碎屑火花；
2. 下面级顶部的 4 台反推火箭工作 1.2 s，使其减速后退并缓慢翻滚，贮箱开口排出推进剂蒸汽；捆绑助推器头尾的分离火箭把它向外推开，机头先向外偏转；
3. 上面级的 4 台沉底发动机工作约 1 s，主发动机在分离 0.8 s 后点火（点火闪光），避免尾焰直接打在下面级上。

这些都是真实的受力：反推、沉底加速度和分离弹簧冲量都进入了动力学计算。

## 物理模型

全部采用真实物理定律，数值积分驱动：

- **引力**：地球、月球、太阳和五颗行星同时作用（地心惯性系下的受限多体问题，含间接项），不是“影响球切换”的近似；轨道预测、机动规划都用同一套积分器（RK4 自适应步长，步长取各天体动力学时间尺度的最小值）。影响球只用于决定“当前天体”、轨道根数与轨迹的分段显示。
- **推进**：齐奥尔科夫斯基方程；比冲随环境气压线性变化（真空发动机在海平面推力大减）；最小节流；固体助推器无法关机或节流；燃料不跨分离器输送。
- **大气**：指数大气（标高 7 km，顶端 70 km），跨音速阻力激增，攻角相关的轴向/法向气动力；压心与质心决定气动稳定性（没有尾翼的火箭在稠密大气中容易翻转），尾翼提供气动操控力矩。
- **刚体姿态**：欧拉方程积分；控制力矩来自指令舱姿态控制系统 + 发动机矢量摆动（推力 × 摆角 × 力臂）+ 尾翼。
- **再入加热**：Sutton-Graves 驻点热流（为降低难度乘以 0.8）+ 蒙皮热容与辐射散热；从月球返回（约 3.1 km/s）必须隔热罩朝前。
- **降落伞**：减速伞（7 km 以下）→ 主伞（2.5 km 以下、< 90 m/s），开伞冲击限制在约 4.5 g。
- **着陆**：弹簧-阻尼接触模型（着陆腿更软），超过零件耐撞速度（已放宽为 1.5 倍）即解体；支持海面溅落。
- **月面地形**：10 个尺度的程序化撞击坑（半径 20 km 到 5 m）+ 丘陵 + 月海。CPU（碰撞）和 GPU（贴图）使用完全相同的整数哈希算法，所以看到的坑就是会撞上的坑。

### 平衡：1:10 地月系统

为了让一枚几十吨的火箭就能完成完整登月（类似《坎巴拉太空计划》的做法），地月系统按 1:10 缩小，**表面重力保持真实值**，时间尺度相应缩为 1/√10，因此所有动力学比例与真实地月系统一致：

| | 地球 | 月球 |
| --- | --- | --- |
| 半径 | 637.1 km | 173.7 km |
| 表面重力 | 9.81 m/s² | 1.625 m/s² |
| 低轨道速度 | ≈ 2.3 km/s（100 km） | ≈ 0.5 km/s（20 km） |
| 自转周期 | 7.57 h | 潮汐锁定 |
| 地月距离 / 月球公转 | 38,440 km / 8.7 天 | 影响球 ≈ 6,600 km |

参考 Δv（m/s）：入轨 ≈ 3400 · 奔月 ≈ 950 · 捕获 + 着陆 ≈ 1000 · 月面起飞 ≈ 750 · 返回 ≈ 300（再入靠大气减速）。总计约 6300~6500。

预设火箭“登月者 L-1”总质量 35.8 t、总 Δv 7460 m/s，测试中自动驾驶完成整趟任务后仍剩约 300 m/s 余量。

## 太阳系

太阳、水星、金星、火星、木星、土星与地月系统使用**同一个 1:10 比例**（半径、距离缩为 1/10，表面重力保持真实，时间缩为 1/√10）。行星在黄道面内做圆轨道运动，初始相位是为游戏挑选的（让火星、金星的窗口不必等太久），**不是真实星历**。

| | 半径 | 表面重力 | 日心距离 | 公转周期 | 影响球 | 大气 | 能做什么 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 太阳 | 69,570 km | 274 m/s² | — | — | — | — | 靠太近会被烤坏（有警告） |
| 水星 | 244 km | 3.7 m/s² | 0.39 AU | 28 天 | 11,200 km | 无 | 环绕、着陆 |
| 金星 | 605 km | 8.9 m/s² | 0.72 AU | 71 天 | 61,600 km | 浓密（100 km） | 环绕、着陆（云层之下才看得见地面） |
| 地球 | 637 km | 9.8 m/s² | 1 AU（1496 万 km） | 116 天 | 92,400 km | 70 km | — |
| 火星 | 339 km | 3.7 m/s² | 1.52 AU | 217 天 | 57,700 km | 稀薄（50 km） | 环绕、着陆、往返 |
| 木星 | 6,991 km | 25.9 m/s² | 5.2 AU | 3.8 年 | 482 万 km | 无地面 | 只能环绕，进入大气会被压垮 |
| 土星 | 5,823 km | 11.2 m/s² | 9.5 AU | 9.3 年 | 545 万 km | 无地面 | 只能环绕（有光环） |

参考：从 100 km 地球轨道飞往火星，转移 Δv ≈ 1100 m/s、飞行约 82 天，中途修正约 20 m/s，火星捕获约 800 m/s（圆化到低轨道；木星、土星只捕获到大椭圆轨道，省很多燃料）。

**行星际规划器**（`src/game/maneuver.ts`）的做法：

1. **猪排图搜索**：在一个会合周期内扫描出发日期 × 飞行时间，用兰伯特问题求日心转移轨道，按“逃逸 Δv + 捕获 Δv + 等待时间”打分；
2. **逃逸几何**：由双曲线超速方向求出停泊轨道上的点火点（考虑停泊轨道倾角带来的平面差），用开普勒外推找到对应的点火时刻；
3. **多体精修**：窗口还远时先给出近似节点，临近窗口（约 1 天前）时自动从当前状态出发，用完整的多体积分对点火时刻和三个 Δv 分量做模式搜索，使目标行星的近拱点落在合适高度（火星约 100 km）；
4. 途中“中途修正”和“捕获”同样基于多体预测。

渲染：太阳为 HDR 发光球体（临边昏暗、米粒组织）加光晕；水星、金星、火星、木星、土星的表面、云带与土星光环都由 GPU 程序化烘焙（火星有奥林帕斯山与极冠，木星有大红斑，金星有带状云）；火星、金星有各自颜色的大气散射（火星的奶油黄天空、金星的昏黄浓云），飞到哪颗星附近就启用哪颗的大气。离太阳越远光照越暗（按距离的平方根衰减，保证外行星仍然看得清）。

## 画面

- **真实地球**：NASA“蓝色大理石”日间地表 + 海底地形、“黑色大理石”夜间城市灯光、水体遮罩（海面高光）和地形起伏图（法线），启动时由 GPU 烘焙成渲染贴图；云层为程序化生成（发射场上空保持晴朗）。贴图加载失败时自动退回程序化地球。
- **地表细节**：在卫星图之上叠加 30 km / 8 km / 2 km 三层程序化细节（颜色斑块 + 起伏凹凸，低太阳角时山脊更立体）、高山积雪，海面有随时间流动的波浪（太阳倒影碎成闪烁的光斑）和近岸浅水色；云层边缘被小尺度噪声侵蚀成一团团积云。细节按每个像素覆盖的地面大小淡入淡出，远看与原图一致、不闪烁。近地面的地形网格上，海面有流动的波浪、岸边有浪花。
- 月球、水星、金星、火星表面由 GPU 程序化烘焙（撞击坑、月海、火山）；碰撞用的地形与看到的地形是同一套算法。
- **近看的细节**：贴图只烘焙到半径约 1.3 km 的撞击坑，更小的撞击坑（520 m、210 m、85 m、34 m……）在星球着色器里按每个像素覆盖的地面大小逐级实时计算，并叠加两层细小的明暗与起伏——放大到离月面、水星、火星表面几十公里时仍然清晰，而且这些坑与物理地形完全一致。远看时这些计算自动跳过。
- **气态巨行星**：多次迭代的流场扭曲让云带边缘卷成涡旋，带边缘有剪切波，细丝沿经度拉长；木星有螺旋结构的大红斑、成串的白色卵形风暴与蓝灰色彩饰，土星北极有六边形；极区布满小气旋。近看时还会实时叠加更细的细丝与小涡旋。
- **太阳**：米粒组织（近看更细）、活动带中成群的太阳黑子（暗本影 + 半影）、靠近临边的光斑，光晕里有几道日冕流光。
- **土星环**：C 环（灰褐、稀薄、有“平台”和麦克斯韦缝）、B 环（最亮、偏暖、由内向外变密）、卡西尼缝（几条暗淡的小环）、A 环（恩克缝、基勒缝），再叠加多个尺度的细密小环（按距离淡入，远处不闪烁）。
- **火星**：奥林帕斯山之外又加了塔尔西斯三火山（阿尔西亚、帕弗尼斯、艾斯克雷尔斯）和水手号峡谷（主峡谷约 300 km 长、18 km 宽、700 m 深，北侧还有一条平行的窄峡谷，按 1:10 缩小）——它们是物理地形的一部分，可以降落在火山坡上或峡谷底部。颜色更丰富（锈红、赭黄、暗色反照率区与风蚀条纹），极冠边缘有螺旋状槽沟。
- **月球、水星的辐射纹**：最新鲜的一批撞击坑带有向外延伸约 3 倍半径的亮条，在月海的暗底上尤其显眼；辐射纹按与物理地形相同的哈希顺序找到同一批撞击坑。
- **地球云层**：云顶有起伏（越厚越高），迎着太阳的一面亮、背面暗，云团显得立体；厚云更白、薄云略灰。
- **金星**云层有斜向条纹与极地云环；**水星**更暗、略带棕色。
- 贴图分辨率：低画质 1024，中画质 2048，高画质的火星、月球与气态巨行星 4096。
- 单次散射大气（瑞利 + 米氏）：蓝天、日落、空中透视、太空中的大气辉光。
- **昼夜**：保留夜面，但夜面有一层略偏冷的补光（约为白天的 38%，越往夜面深处略暗），地形、云层依然看得清；晨昏线是一段较宽的渐变而不是硬边，附近带一点夕阳的暖色。飞行视图里夜间的地面和火箭也有相应的补光。
- 近地表使用以飞船为中心的同心圆 LOD 地形网格（双精度计算，Web Worker 生成）。
- 泛光 + ACES 色调映射，发动机尾焰（激波菱形、真空膨胀）、烟雾、爆炸、再入等离子体，发射塔与发射场。
- 音效全部由 WebAudio 实时合成。
